# Знеструмко

Telegram-бот стежить за графіками відключень від `be-svitlo.oe.if.ua`, надсилає сповіщення підписникам і має меню адміністратора в Telegram.

## Запуск у Windows

1. Встановіть Python 3.11 або новіший.
2. Запустіть `setup.bat`, щоб встановити залежності.
3. Скопіюйте `.env.example` у `.env`. Заповніть `BOT_TOKEN` токеном від BotFather.
4. Запустіть бота через `start.bat` або командою `python bot.py`.

Якщо `.env` уже існує, не перезаписуйте його — додайте до нього лише потрібні змінні. `.env` не комітьте й не надсилайте: там є секрети.

## Адміністратор у Telegram

1. Напишіть боту `/myid`, щоб дізнатися свій числовий Telegram ID.
2. Додайте його в `.env`: `ADMIN_USER_IDS=123456789`. Для кількох адміністраторів перелічіть ID через кому.
3. Перезапустіть бота та надішліть йому `/admin`.

Меню дозволяє переглядати сьогоднішній і завтрашній графік будь-якої черги, примусово оновлювати одну або всі черги, вмикати/вимикати розсилку нагадувань і змін графіка та переглядати останні логи. Команда `/myid` лише показує ID відправника; без ID у `ADMIN_USER_IDS` команда `/admin` недоступна.

## FadeHost

У FadeHost створіть Telegram bot зі свого GitHub-репозиторію та задайте Start command `python bot.py`. Додайте змінні `BOT_TOKEN` і `ADMIN_USER_IDS`; для постійного збереження бази додайте `BOT_DB_PATH=/data/bot.sqlite3`. Секрети задавайте у змінних середовища FadeHost, не в GitHub.

## Можливості бота

- Команди `/subscribe 5.2`, `/unsubscribe 5.2`, `/tomorrow 5.2`, `/subscriptions`.
- Графік у форматі цитати з сумарною тривалістю відключень за день.
- Автоматичне нагадування підписникам за 10 хвилин до відключення.
- Моніторинг графіків щохвилини та докладні логи оновлень, сповіщень і помилок.
