# Знеструмко

Telegram-бот стежить за графіками відключень від `be-svitlo.oe.if.ua`. Вебадмінка показує стан бота, кеш графіків, підписки та live журнал подій; з неї можна примусово оновити одну чергу або всі черги.

## Локальний запуск у Windows

1. Встановіть Python 3.11 або новіший.
2. Запустіть `setup.bat` — він створить `.venv` та встановить залежності.
3. Скопіюйте `.env.example` у `.env`, задайте `BOT_TOKEN` і власний довгий `ADMIN_TOKEN`.
4. Запустіть `start.bat` і відкрийте `http://localhost:8080`.

У `.env` не додавайте цей файл до Git: токени є секретами.

## Деплой на FadeHost

Створіть Python app із GitHub-репозиторію та задайте:

- **Start command:** `python web_admin.py`
- **Environment variables:** `BOT_TOKEN=...`, `ADMIN_TOKEN=...`, `BOT_DB_PATH=/data/bot.sqlite3`
- Увімкніть **Web address** у налаштуваннях застосунку.

Застосунок слухає `0.0.0.0` на порті з `PORT`. Змінна `BOT_DB_PATH` зберігає SQLite у постійному томі FadeHost, бо файли поруч із кодом можуть бути очищені під час деплою. Токени додавайте лише у змінні середовища FadeHost, не в репозиторій.

Інтерфейс використовує React 18 та HTM з версіями, закріпленими в URL esm.sh; окремий Node build для адмінки не потрібен.

## Адмінпанель

- Стан Telegram-бота, кількість підписок і час останньої перевірки.
- Кешовані графіки всіх черг з періодами та сумарним часом відключення.
- Live журнал підписок, оновлень графіків, примусових оновлень, нагадувань та помилок.
- Примусове оновлення однієї черги або всіх черг. Успішно отриманий графік надсилається підписникам.

Для захисту панелі задайте випадковий секрет у `ADMIN_TOKEN`. Після відкриття вебадреси введіть його у форму входу. API та live WebSocket перевіряють токен; доступ до панелі не відкривається, якщо токен не налаштований.

## Telegram-функції

Доступні команди `/subscribe 5.2`, `/unsubscribe 5.2`, `/tomorrow 5.2` і `/subscriptions`. У графіку та таймері показується загальна запланована тривалість відключень за день. Для підписаних черг бот надсилає нагадування за 10 хвилин до вимкнення. Графіки перевіряються щохвилини, а повідомлення про зміну надсилається після оновлення.
